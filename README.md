# Breast Cancer Detection Using Deep Learning

This project detects breast cancer from histopathology images using deep learning.  
It classifies images into **Cancer (IDC+)** and **Non-Cancer (IDC−)** using a **MobileNetV2 transfer learning model**.

## Features
- Binary classification (Cancer / Non-Cancer)
- MobileNetV2 transfer learning
- Accuracy and loss visualization
- Confidence-based cancer prediction

## Technologies Used
- Python
- TensorFlow / Keras
- MobileNetV2
- NumPy
- Matplotlib

## Dataset Structure
dataset/
├── Cancer (IDC+)/
└── Non-Cancer (IDC-)/

## How to Run
1. Open the notebook in Google Colab  
2. Upload the dataset  
3. Run all cells
